震源球デコーダー

地震の「震源球（ビーチボール図）」を、お椀・球面・断層ブロック・地表の動きに置き換えて読み解きます。3Dの図はドラッグで回せます。

代表例:
モーメントテンソルから入力する（GCMT・USGS形式）

Mrr Mtt Mpp Mrt Mrp Mtp（r=上, t=南, p=東）。二重couple以外の成分（CLVD・等方）は無視し、最も近い二重couple成分を使います。

②③は同じ視点で連動します。

数値

節面A
節面B
P軸
T軸

読み方

  • 黒＝初動が「押し」（震源から遠ざかる向きに地面が動く）、白＝「引き」。
  • 黒い領域の中心付近に T軸、白い領域の中心付近に P軸 がある（名前と色が逆で紛らわしい）。
  • 赤線は2本の節面。実際の断層面は A か B の一方で、地震波の初動だけでは決められません（余震の並び・地表の断層・津波・地殻変動などと突き合わせて判断します）。
  • 平らな震源球は「球の下半分（お椀）を真上から見た図」。②で斜めから、③で球全体として見られます。

震源球デコーダー — 計算は Python 版（beachball_decoder/fault.py）と同じ式で、結果を自動テストで照合しています。
