# beachball_decoder（震源球デコーダー）

地震学の **震源球（ビーチボール図）** を、専門知識がなくても直感的に理解できる図へ変換するソフトウェア。

詳しくは [MANUAL.md](MANUAL.md) を参照。

> 状態: Phase 0〜3 実装済み（2026-10-25）。ブラウザ版は [web/](web/)。公開カタログ連携（Phase 4）以降は未着手。

## 使い方

### ブラウザ版（ドラッグで回せる）
公開ページ: https://masauehr.github.io/beachball_decoder/

[web/index.html](web/index.html) をブラウザで開く（サーバー不要・外部ライブラリなし）。走向・傾斜・すべり角のスライダーで、平らな震源球・お椀・球面・断層ブロック（節面A/B）・地表の初動マップが連動して変わる。3Dの図はドラッグ（タッチ・矢印キーも可）で回転。詳しくは [web/README.md](web/README.md)。

### Python 版（画像・ノートブック）

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt   # 初回のみ
.venv/bin/python -m beachball_decoder --preset thrust -o out.png      # 代表例（thrust/normal/strike_left/strike_right/oblique）
.venv/bin/python -m beachball_decoder --strike 30 --dip 45 --rake 90 -o out.png
.venv/bin/python -m beachball_decoder --mt 1.7 -0.3 -1.4 0.5 -0.2 0.9 -o out.png   # Mrr Mtt Mpp Mrt Mrp Mtp（GCMT/USGS形式）
```

出力は1枚の画像: 震源球 / **下半球を立体のお椀として斜めから見た図** / 節面Aが断層面の場合のブロック図 / 節面Bの場合のブロック図 / 地表の初動マップ / 解説文。
例は [examples/](examples/)（[逆断層](examples/thrust.png)・[正断層](examples/normal.png)・[左横ずれ](examples/strike_left.png)・[右横ずれ](examples/strike_right.png)・[斜めずれ](examples/oblique.png)）。

動作確認ノートブック: [notebooks/01_decoder_tour.ipynb](notebooks/01_decoder_tour.ipynb)
（実行結果をそのまま載せた [notebooks/README.md](notebooks/README.md) もある。数式・震源球・ブロック図・地表マップの確認と、スライダーで走向・傾斜・すべり角を動かす試験。カーネルは `.venv` を選ぶ。出力は消してコミットしている）

平面・お椀・球面全体の3つを並べた図は、`--trio out_trio.png`（`--elev` で見る高さ。既定30°）で出力する。
例: [逆断層](examples/thrust_trio.png)・[正断層](examples/normal_trio.png)・[左横ずれ](examples/strike_left_trio.png)

テスト（開発用）: `.venv/bin/pip install -r requirements-dev.txt && .venv/bin/python -m pytest tests`

## 背景と課題

震源球は、地震の **断層の向きとずれ方（発震機構）** を1枚の円で表す図。

- 球を断層面と補助面で4つの象限に分け、**押し（圧縮）= 黒**、**引き（膨張）= 白** で塗り分ける
- 震源を中心とした球の **下半球** を平面に投影したもの（等面積投影＝シュミットネット、または等角投影）
- 黒（押し）の象限の中心付近に **引張軸（T軸）**、白（引き）の象限の中心付近に **圧縮軸（P軸）** がある。名前と色が逆で紛らわしいので、このアプリでは図中に明示する

### 初学者がつまずく点

1. 球の下半分を上から見た図、という **3次元→2次元の投影** を頭の中で戻せない
2. 2本の節面（境界線）のうち **どちらが本当の断層面か分からない**（補助面との曖昧性）
3. 黒白の模様と **実際の地面の動き（上下・水平）** が結びつかない
4. 正断層・逆断層・横ずれ断層が、模様のどの形に対応するのか分からない

## 目的

震源球（またはそれを定義するパラメータ）を入力すると、次のような **直感的な図** を出力する。

## 出力する図（案）

| 図 | 内容 | 解決する課題 |
|----|------|-------------|
| 3D回転球 | 色分けされた球をドラッグで回転。下半球を強調し、投影される様子をアニメーション表示 | 課題1 |
| ブロック図 | 断層面を境に2つの岩盤ブロックが動く様子を矢印で表示（3D） | 課題3・4 |
| 地面の動き図 | 震源の真上の地面が「押される／引かれる」方向を、観測点の方位ごとに矢印で表示 | 課題3 |
| 断層タイプ判定 | 正断層／逆断層／横ずれ断層（または斜めずれ）を文章とアイコンで説明 | 課題4 |
| 地図上の断層線 | 断層の走向を地図に線で重ねる（例: 北東–南西走向） | 課題3 |
| 2面の切替表示 | 節面A・節面Bをそれぞれ「断層面だった場合」の図として並べて表示 | 課題2 |

## 入力

優先順位の高い順:

1. **断層パラメータ**: 走向（strike）・傾斜（dip）・すべり角（rake）
2. **モーメントテンソル**: Mrr, Mtt, Mpp, Mrt, Mrp, Mtp（GCMT・USGSの形式）
3. **公開カタログからの取得**: USGS・GCMT・防災科研 F-net・気象庁などの発震機構解
4. （将来）**ビーチボール画像**の読み取り → パラメータ推定（画像認識）

## 基本方針

- 計算の核心は **断層パラメータ ⇄ モーメントテンソル ⇄ 節面・P/T軸** の相互変換
- ビーチボールの描画は、まず標準的な手法（下半球・等面積投影）を正確に再現し、既存ライブラリ（ObsPy の beachball 等）の出力と照合して検証する
- 「どちらが断層面か分からない」ことを **隠さず図で示す**（片方に断定しない）
- 色は黒白だけに頼らず、断層タイプごとの色分けを併用（色覚多様性に配慮）
- 各アプリは独立して動作する自己完結構成（`common/` への依存を避ける）

## 確認・検証

- 代表的な断層（純粋な正断層・逆断層・左横ずれ・右横ずれ）の模様が教科書の図と一致すること
- 既知の地震（例: 過去の大地震のGCMT解）で、公表されている図と一致すること
- 節面の入れ替え（走向・傾斜・すべり角の補助面への変換）で、元の模様が変わらないこと
